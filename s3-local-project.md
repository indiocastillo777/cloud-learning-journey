# AWS S3 Local Practice Project

## Overview
This project was created to practice the basics of file storage and management before working with actual AWS S3 buckets.

I used my MacBook's Terminal to simulate uploading, downloading, and verifying files.

## What I Did
- Created a local folder to represent an S3 bucket.
- Created a text file to use for testing.
- Copied the file into the practice bucket.
- Copied the file back into a separate downloads folder.
- Compared the original and downloaded files to make sure they matched.

## Commands Used
- mkdir
- ls
- echo
- cat
- cp
- diff

## What I Learned
I learned how files can be organized, copied, and checked using Terminal commands. I also practiced the basic workflow behind uploading and downloading files from cloud storage.

## Next Steps
My next goal is to work with an actual AWS S3 bucket and continue building my cloud computing skills.

## Note
This was a local practice project. No actual AWS S3 bucket was created.
